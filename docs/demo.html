Run log

    Replays use data extracted from the runs' QA snapshots by docs/build_demo_data.py. Step times come from when each snapshot was written. The snapshots keep each step's final output but not the timing of individual tokens, so streamed text is revealed at an even pace across the step's real duration. Parallel section writers are recorded as finishing together, so they're shown that way. To write your own post, see the installation steps.
