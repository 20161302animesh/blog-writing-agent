Blog Writing Agent

Give it a topic. It researches the web, plans the piece, writes it, has an editor check every claim against the sources, then tags and saves a ready-to-publish Markdown post.

Get started Watch a replay How it works

Two kinds of post, two ways of writing

A tutorial and an opinion piece need different structures, so the agent picks a branch for each topic. Both share the same research at the start and the same tagging and saving at the end.

Technical

Engineering, AI, developer tools, tutorials, system design

  1. Outline of 5–9 sections, each with a goal and bulletsSonnet
  2. One writer per section, running in parallel. Broken code is rewritten.Sonnet
  3. Grounding check: small fixes to claims the sources don't supportOpus

Analysis

Media, culture, business, society, opinion

  1. A thesis, 3–6 argument beats and the strongest counterpointSonnet
  2. One writer drafts the whole piece, so the argument holds togetherSonnet
  3. Editor revises for argument, sources, reasoning, prose and lengthOpus

Before either branch, Haiku classifies the topic, decides whether it needs research, and turns Tavily results into clean evidence. After it, Haiku adds 5–8 tags. See the full pipeline.

Built to keep the writing honest

Sources come only from search

Evidence the search didn't return is dropped, so the model can't invent a source.

Claims checked against source text

The editor reads what each source actually says, not a summary of it.

Code that runs

Python examples must parse. A failing section is rewritten with the problems spelled out.

No new links in fixes

An edit that adds a URL outside the evidence is rejected.

Every change on record

Each run saves a snapshot per step and a sentence-level diff of the editor's changes.

Resumable runs

With a checkpoint file, a crashed run continues where it stopped without paying twice.

Quick start

Python 3.11 or later, plus an Anthropic API key and a Tavily API key.

Install and run

# clone, install, add your keys
git clone https://github.com/20161302animesh/blog-writing-agent
cd blog-writing-agent
pip install -e .
cp .env.example .env

# write a post
python -m blog_agent "Your topic" --kind auto -v

Call it from Python

from blog_agent import write_blog

result = write_blog(
    "Will Indian OTT ever have its Ted Lasso moment?",
    kind="analysis",
    target_words=800,
)
print(result.title)
print(result.output_path, result.estimated_cost_usd)

Credits

This project grew out of the blog-writing-agent exercise by CampusX (Nitish Singh). Its notebooks built the original technical pipeline on OpenAI models: a router, Tavily research, an orchestrator, parallel section writers and a reducer. This project ports it to Claude and extends it with the analysis branch, the editor and grounding checks, and a callable package. Thanks to CampusX and Nitish Singh for the idea and the starting point.
